# 🎶 Music Recommendation System

An AI-powered music recommendation system that suggests songs based on **lyrical similarity** using TF-IDF and cosine similarity — wrapped in a polished, animated Streamlit app with mood-aware backgrounds and dynamic emojis.

![Python](https://img.shields.io/badge/python-3.9+-blue.svg)
![Streamlit](https://img.shields.io/badge/streamlit-app-red.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Features

- **Lyrics-based recommendations** — finds songs with the most similar lyrical content using TF-IDF vectorization + cosine similarity
- **Mood-aware theming** — detects the "vibe" of a song (romantic, party, sad, chill, intense, dreamy) from keywords in its lyrics and shifts the entire UI (gradient background, accent color, floating emojis) to match
- **Glassmorphism UI** — animated, modern song cards with hover effects and similarity score bars
- **Shuffle mode** — discover a random song with one click
- **Downloadable playlist** — export your recommendations as a `.txt` file
- **Demo mode** — runs out of the box with a small built-in dataset even before you've trained on the full data

[Spotify Million Song Dataset](https://www.kaggle.com/datasets/notshrirang/spotify-million-song-dataset/data) (Kaggle) — contains artist, song title, and full lyrics for thousands of songs.

## 🚀 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/<your-username>/music-recommendation-system.git
cd music-recommendation-system
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Prepare the data (optional — skips to demo mode if not done)

Download `spotify_millsongdata.csv` from the [Kaggle dataset link](https://www.kaggle.com/datasets/notshrirang/spotify-million-song-dataset/data) above, then run:

```bash
python prepare_data.py --csv spotify_millsongdata.csv --sample 10000
```

This cleans the lyrics, fits a TF-IDF vectorizer, and saves all artifacts into `artifacts/`.

| Argument | Description | Default |
|---|---|---|
| `--csv` | Path to the raw dataset CSV | *required* |
| `--sample` | Number of songs to sample (`0` = full dataset) | `10000` |
| `--out_dir` | Output folder for artifacts | `artifacts` |
| `--max_features` | Max TF-IDF vocabulary size | `5000` |

### 4. Run the app

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser.

## 🧠 How It Works

1. **Preprocessing** — lyrics are lowercased, stripped of special characters/numbers, tokenized, and stopwords removed (NLTK)
2. **Vectorization** — cleaned lyrics are converted to TF-IDF vectors (top 5,000 terms)
3. **Similarity** — cosine similarity between the selected song's vector and all other songs ranks the closest matches
4. **Mood detection** — lyrics are scanned for keyword groups (love, party, sad, chill, angry, dreamy) to pick a theme for the UI

## 🌐 Deployment

This app is ready to deploy on [Streamlit Community Cloud](https://share.streamlit.io):

1. Push this repo to GitHub (include the `artifacts/` folder)
2. Go to share.streamlit.io → **New app**
3. Select your repo, branch, and set the main file to `app.py`
4. Click **Deploy**

> **Note:** Keep `artifacts/` under GitHub's file size limits. If your pickled files are large, reduce `--sample` or `--max_features` in `prepare_data.py`, or use [Git LFS](https://git-lfs.github.com/).
